# Project source

`screening/` contains the hospital, risk service, numerical contract, model, UI and measurement commands. `data_prep/` contains reproducible source-data preparation. Reusable code belongs here; notebooks import it rather than duplicate the protocol.

All identifiers, comments, docstrings, help and authored messages use English. Original source column names remain exact identifiers and are explained in the data documentation. See the factual build chronology in `docs/TIMELINE.md` and run `make verify` after changes.

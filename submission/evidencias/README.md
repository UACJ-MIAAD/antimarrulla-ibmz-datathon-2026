# Historical evidence archive

These original records and screenshots describe earlier commits and environments. Preserve their bytes, language, dates, hashes and platform labels. They are historical evidence, not current English release instructions.

Write all new English records under [`submission/evidence/`](../evidence/README.md). Use its English `RECORD.example.json` templates. Obsolete Spanish templates have been retired; their originals remain in Git history.

Local Mac/arm64 measurements do not establish LinuxONE execution. The current release gates remain in `docs/SUBMISSION_CHECKLIST.md`.
